# 与 AI 协作改简历

参考：[小红书笔记《怎么让AI给你改简历》](https://xhslink.cn/o/5rIKEPJQXLc)。核心方法经过概括后写入本 skill，不依赖每次联网读取原帖。

## 问题

只对 AI 说“帮我优化一下简历”，通常会得到“负责、参与、提升、协助、具备良好能力”等空话。原因是 AI 不知道目标岗位、招聘方判断标准和真实事实边界。

正确输入必须同时包含：

1. 目标岗位 JD。
2. 当前简历。
3. 可验证的事实和角色边界。
4. 明确禁止编造经历、数据和结果。

## 招聘方角色

分析开始时设定：

```text
你现在是一名有多年招聘经验的 HR，同时也是这个岗位的面试官。
请站在招聘方角度，根据 JD 判断候选人能否解决问题、证据是否可信、招聘风险是否可接受。
先不要直接改写。
```

不要只让 AI“润色”。要求它先完成诊断，再提出修改。

## 六步诊断顺序

1. 找出岗位最看重的 5 项能力及 JD 关键词。
2. 逐条检查简历：哪些经历最匹配，哪些内容与岗位无关、可以删除。
3. 指出简历为什么可能让 HR 跳过，包括关键词缺失、结果弱、顺序差和信息噪音。
4. 在不编造经历和数据的前提下改写。每段经历回答“做了什么 -> 怎么做 -> 结果怎么样”。
5. 标出应该自然进入简历的岗位关键词，并说明放在哪里。
6. 生成一份可直接投递的完整简历。

## 改写约束

- 不写“负责、协助、参与、具备良好能力”之类没有信息量的空话，除非角色边界确实只能证明参与。
- 语言简洁、具体、克制。
- 所有内容必须基于真实经历。
- 每条改写必须能回到 JD 要求和已验证证据。
- 没有数字时，写规模、频率、范围、排名或对比；这些都不存在时保留事实，不补造。

## 30 秒 HR 红队复核

完成初稿后，不立即确认，先执行：

```text
现在不要帮我改。假设你是这个岗位的 HR，只看我的简历 30 秒，
告诉我你会不会让我进入面试。如果不会，最可能卡在哪里？
```

复核结果写入 `requirements.json.thirty_second_review`：

```json
{
  "would_interview": false,
  "decision": "经历相关，但最先看到的是执行细节，不是岗位要求的增长和闭环结果。",
  "where_stuck": [
    "第一屏没有出现增长或留存指标",
    "最强结果放在第二页"
  ],
  "improvements": [
    "将增长结果前置到最近经历第一条",
    "删除与目标岗位无关的执行流水账"
  ]
}
```

处理规则：

- 如果卡点是表达、排序或关键词，先修改，再复核一次。
- 如果卡点是真实证据缺口，标记为 `gap`，不能编造。
- 最终仍需用户确认，不能因为模拟 HR 给出肯定答案就跳过 Gate 2。

## 输出检查

招聘方在几十秒内应该看懂：

```text
你是谁 -> 做过什么 -> 做出过什么结果 -> 为什么适合这个岗位
```

若其中任一环节需要猜测或翻找，继续压缩、前置或重写。
